# Independent track-layout fixtures

These are packed clock/data bits generated by Greaseweazle (not flux samples).
All contain our own deterministic pattern, cylinder 43, head 0, sectors starting
at ID 1. `make_layout_fixtures.py` records the pattern and generation parameters;
`manifest.json` records hashes. No original software or private disk data is used.

Generated with Greaseweazle commit `26690f8` using its `ibm.1440`, `ibm.720`, and
explicit 26 x 128-byte IBM FM / 250 kbit/s / 360 RPM definitions. Run the generator
with that checkout's `src` directory on `PYTHONPATH` if regeneration is needed.

`test_track_layout.c` compares every clock/data bit, including headers, CRCs,
sync patterns, inter-sector gaps, and the final pre-index gap. This is software
interoperability evidence, not a substitute for physical drive/media tests.
