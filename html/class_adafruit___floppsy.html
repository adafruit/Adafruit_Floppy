Detailed Description

Board setup for RP2350 Floppsy in drive-controller mode.

Own one instance per board. The two drive interfaces share the cable and motor signal; select only one drive at a time. Call begin(), check the supply voltages required by your drive, then enable(true) before drive operations. Display, touch, SD, USB host, and drive-emulation setup are separate.

bool Adafruit_Floppsy::begin ( )

Initialize the drive pins, level shifters, BOOT button, and power monitor.

Returns
True when both drive interfaces and the power monitor are initialized.
Note
The cable remains isolated on both success and failure. No drive is selected, no motor starts, and write gate remains inactive. Repeat calls stop any active drive and restore the default drive timings.

bool Adafruit_Floppsy::enable ( bool  enabled)

Connect the drive interface, or stop both drives and isolate the cable.

Parameters
enabledTrue to connect the controller signals; false to stop/isolate.
Returns
False if enabling before a successful begin(); true otherwise.
Note
This controls signal buffers, not drive power. The caller must check the rails required by its drive. Enabling does not require 12 V universally. Use only between synchronous drive operations, not during capture or writing.
